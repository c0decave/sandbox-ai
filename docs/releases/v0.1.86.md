# sandbox-ai 0.1.86

The desktop app as asked for, and work of 2026-11-07 that never reached a release.

**Desktop app**
- **One log window** at the bottom of every page (folded at first, undockable): every message, warning and error of
  the app, with a level to show from (Errors, Warnings, Info, Debug), a filter, Copy and Clear. The board's notes go
  there instead of lines above it. `--debug` no longer floods the terminal (it turned on every Qt category):
  debug entries go to the log window and `app.log`; `--debug=all` is the old flood.
- **Board:** a part's properties open on a double click (a click selects, held it moves), with OK, Cancel and Remove;
  an [x] on each part that may go (asks first; Settings: off); the CLI command behind its button; "Fit" is
  "Zentrieren" in German; no folder row (the window's header names the project); an empty session name gets a
  codename; Ctrl+S applies; changes are kept at once when the page or project changes, with up to 20 steps of Undo
  that come back after a restart; the MCP server is chosen from every server there is; "Project folder" and "Extra
  folder" (were Workspace and Mount) say what each is for.
- **Questions:** one prompt per question - the app's notification answers it (Allow, Allow always, Block, Block
  always); while the app notifies, the launcher shows no second notification of its own (a heartbeat).
- **Terminals:** the Sessions list under the terminals, folded at first; no explanatory sentence above them.
- **Header:** one project switcher (name, path on hover) and the project file's trust as an icon with its meaning.
- **Start page:** each project tab shows that project's own values; a new project starts from the defaults.
- **Crashes:** a run that ended without quitting (killed from outside, out of memory) is said at the next start, with
  its memory, its page and the out-of-memory killer's lines where the kernel's log tells; the app's memory above
  2 GiB is logged; a terminal page that ends is logged. A closed window no longer keeps its backend alive.

**Command line and web**
- `sandbox-ai usage`: CPU and processes beside memory; throttling and `--pids` warnings.
- `sandbox-ai llm detect` and local models in the project wizard; `--llm NAME:MODEL,MODEL...`.
- One prompt per question for the web interface too; a canary's alarm is always shown.
- Bug hunt: web requests always answered (404/400/500), terminal sizes checked, nothing sent after a close frame,
  modules loaded once under a lock, a host's command under `~/` expanded; launcher, supervisor and session fixes
  (frozen children, hooks in their own process group, a stuck question freed, PID reuse).
