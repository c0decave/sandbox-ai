# sandbox-ai 0.1.85

The work of 0.1.76 to 0.1.84 merged with the private line's own 0.1.76:

- **Safeguard warnings:** when a safeguard refuses or ends something in a sandbox (the firewall, a name lookup, the
  proxy, a rule, a question nobody answered, the privacy check of a push, the security mode, the administrator's
  policy, the run's taint, a device, memory, a canary), it is recorded with why and what would allow it, and shown as
  a grouped warning - in the desktop app (Activity > Safeguards), in the web interface (page Safeguards) and with
  `sandbox-ai safeguards`. Kinds can be muted (`safeguard_mute` in `sandbox-ai defaults`); they stay listed.
- **Ten more themes** (Solarized Dark and Light, Dracula, Nord, Gruvbox Dark, One Dark, Catppuccin Mocha and Latte,
  Tokyo Night) and an interface and a monospace font of your choice in the app and the web interface; only fonts
  installed on the machine are used, nothing is downloaded.
- The web interface's new safeguard and font texts in German too.
