# sandbox-ai 0.1.87

**A session to another host.** `sandbox-ai session copy NAME HOST` starts a session's configuration again on a host
of `sandbox-ai hosts`: its options with what its trusted project file added (passed with `--no-config`, so exactly
this starts there), checked first with a dry run on that host. `session move` then stops it here (its HOME stays
until `session delete`). `--map LOCAL=REMOTE` moves folders that lie elsewhere there, `--as NAME` renames it,
`--check` only checks, `session plan NAME --json` shows what a copy starts with. Logins and HOME are not copied; a
project's own MCP servers and ruleset are named and nothing starts. In the desktop app: Copy to host… and Move to
host… on the Sandboxes page, with the folders to map pre-filled.
